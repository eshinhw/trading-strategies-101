# Quiz

1. {#bk1} [calc] An equity tranche position has a CS01 of $12,000 per basis point. The index CS01 is $400 per basis point per $1 million notional. What index notional hedges the position?
   - $3 million
   - $300 million
   - [x] $30 million
   - $4.8 million
   > Hedge notional = $12,000 / $400 per $1 million = 30, so $30 million.

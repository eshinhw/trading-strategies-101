# Quiz

1. {#bk1} [calc] An index returns 10% while a fund tracking it holds 2% in cash earning 1%, with the rest matching the index. How much return does the cash drag cost?
   - [x] 0.18%
   - 0.10%
   - 0.20%
   - 1.00%
   > The 2% in cash earns 1% instead of 10%, a 9% shortfall: 2% × 9% = 0.18%.

2. {#bk2} [calc] An index returns 8.40% for the year. A fund tracking it charges a 0.15% fee and loses 0.05% to trading costs. What is the expected fund return?
   - 8.25%
   - 8.40%
   - [x] 8.20%
   - 8.60%
   > The fund returns the index return minus costs: 8.40% − 0.15% − 0.05% = 8.20%.

# Quiz

1. {#bk1} [calc] A stock's daily returns have a standard deviation of 1.2%. Using 252 trading days, what is its annualized volatility?
   - [x] 19.0%
   - 302.4%
   - 14.4%
   - 22.9%
   > Annualized volatility = daily volatility × √252 = 1.2% × 15.87 = 19.0%.

2. {#bk2} [calc] A stock's daily returns have a standard deviation of 0.8%. Using 252 trading days, what is its annualized volatility?
   - 201.6%
   - 9.6%
   - [x] 12.7%
   - 15.3%
   > Annualized volatility = daily volatility × √252 = 0.8% × 15.87 = 12.7%.

   - [x] 31.7%
   - 504.0%
   - 24.0%
   - 38.2%

4. {#bk4} [calc] A stock at $100 has 30% annualized volatility. What is its approximate one-standard-deviation move over one month?
   - $30.00
   - $2.50
   - $17.32
   - [x] $8.66
   > One month is 1/12 of a year, so the move is 30% × √(1/12) = 8.66%, or $8.66.

# Quiz

1. {#bk1} [calc] An investor buys a $500,000 property with a 20% down payment, financing the rest. The property value rises 5%. Ignoring other costs, what is the return on the investor's equity?
   - 5%
   - [x] 25%
   - −25%
   - 12.5%
   > Equity invested is $100,000. The value change is $25,000. Return = $25,000 / $100,000 = 25%, which is 5% multiplied by the 5× leverage.

2. {#bk2} [calc] An investor buys a $400,000 property with a 25% down payment, financing the rest. The property value falls 10%. Ignoring other costs, what is the return on the investor's equity?
   - −10%
   - 40%
   - −20%
   - [x] −40%
   > Equity invested is $100,000. The value change is −$40,000. Return = −$40,000 / $100,000 = −40%, which is 10% multiplied by the 4× leverage.

3. {#bk3} [calc] An investor buys a $600,000 property with a 10% down payment, financing the rest. The property value rises 4%. Ignoring other costs, what is the return on the investor's equity?
   - 4%
   - [x] 40%
   - −40%
   - 20%
   > Equity invested is $60,000. The value change is $24,000. Return = $24,000 / $60,000 = 40%, which is 4% multiplied by the 10× leverage.

4. {#bk4} [calc] A rental property earns $36,000 in rent a year. Operating costs are $12,000 and mortgage payments are $18,000. The investor put in $100,000 of their own cash. What is the cash-on-cash return?
   - 24%
   - 12%
   - [x] 6%
   - 36%
   > Cash flow is $36,000 − $12,000 − $18,000 = $6,000. Cash-on-cash return = $6,000 / $100,000 = 6%.

5. {#bk5} [calc] A $500,000 property is bought with a $400,000 loan. What is the loan-to-value ratio?
   - [x] 80%
   - 20%
   - 125%
   - 25%
   > Loan-to-value = $400,000 / $500,000 = 80%.

# Quiz

1. {#bk1} [calc] A strategy targets 10% annualized volatility. The index's recent realized volatility is 16%, and the investor has $2,000,000. What index exposure should the strategy hold?
   - $3,200,000
   - $2,000,000
   - [x] $1,250,000
   - $200,000
   > Leverage = target / realized = 10% / 16% = 0.625. Exposure = 0.625 × $2,000,000 = $1,250,000.

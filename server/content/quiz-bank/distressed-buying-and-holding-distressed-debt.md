# Quiz

1. {#bk1} [calc] A bond bought at 60 is expected to be worth 100 in 2 years after restructuring. What is the annualized return?
   - [x] 29.1%
   - 66.7%
   - 33.3%
   - 40%
   > Total return = 100 / 60 = 1.667. Annualized = 1.667^(1/2) − 1 = 29.1%.

2. {#bk2} [calc] A distressed bond has a 70% chance of recovering 80 and a 30% chance of recovering 20. It trades at 55. What is the expected recovery and the expected return?
   - 50, an expected return of −9%
   - 62, an expected return of 12%
   - [x] 62, an expected return of 12.7%
   - 80, an expected return of 45%
   > Expected recovery = 0.70 × 80 + 0.30 × 20 = 62. Expected return = (62 − 55) / 55 = 12.7%.

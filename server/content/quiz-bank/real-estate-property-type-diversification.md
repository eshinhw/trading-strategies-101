# Quiz

1. {#bk1} [calc] A portfolio holds 60% apartments returning 6% and 40% offices returning 3%. What is the portfolio return?
   - 4.5%
   - 9%
   - 3.6%
   - [x] 4.8%
   > 0.60 × 6% + 0.40 × 3% = 3.6% + 1.2% = 4.8%.

2. {#bk2} [calc] Two property types each have a volatility of 10% and a correlation of 0.5. What is the volatility of a 50/50 portfolio?
   - 10%
   - [x] 8.66%
   - 5%
   - 7.07%
   > Variance = 0.25 × 0.01 + 0.25 × 0.01 + 2 × 0.25 × 0.5 × 0.01 = 0.0075. Volatility = √0.0075 = 8.66%.

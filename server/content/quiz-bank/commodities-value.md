# Quiz

1. {#bk1} [calc] A commodity trades at $60 and its 5-year average price is $75. What is the ratio of price to long-run average?
   - [x] 0.80
   - 1.25
   - 0.20
   - 15
   > $60 / $75 = 0.80, so the commodity is 20% below its long-run average.

2. {#bk2} [calc] A value rule buys commodities whose price is below 90% of the 5-year average. A commodity trades at $60 against a 5-year average of $75. Is it a buy, and how far below the average is it?
   - No, 20% above
   - Yes, 25% below
   - [x] Yes, 20% below
   - No, 10% below
   > 60 / 75 = 0.80, which is below 0.90, so the rule buys. The price is 20% below the average.

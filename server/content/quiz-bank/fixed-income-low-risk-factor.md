# Quiz

1. {#bk1} [calc] A low-risk bond portfolio has 4% volatility and the investor targets 8% volatility. How much leverage scales the portfolio to the target?
   - [x] 2×
   - 0.5×
   - 4×
   - 1×
   > Leverage = target / portfolio volatility = 8% / 4% = 2×.

2. {#bk2} [calc] A low-duration bond portfolio returns 5%. It is levered 2× by borrowing at 2%. What is the return on the investor's own money?
   - 10%
   - 6%
   - [x] 8%
   - 7%
   > Levered return = 2 × 5% − 1 × 2% = 8%.

3. {#bk3} [calc] A low-duration bond portfolio returns 4% with 2% volatility, and a high-duration portfolio returns 6% with 6% volatility. The risk-free rate is 1%. What is each portfolio's Sharpe ratio?
   - [x] 1.5 for low duration and 0.83 for high duration
   - 2.0 and 1.0
   - 0.75 and 0.83
   - 1.5 and 1.0
   > Low: (4 − 1) / 2 = 1.5. High: (6 − 1) / 6 = 0.83.

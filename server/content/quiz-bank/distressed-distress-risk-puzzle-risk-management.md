# Quiz

1. {#bk1} [calc] A manager limits each distressed position to a maximum loss of 2% of the portfolio. A position could lose 50% of its value in the worst case. What is the largest position size?
   - 2%
   - 1%
   - [x] 4%
   - 25%
   > Size × 50% = 2%, so size = 2% / 50% = 4% of the portfolio.

2. {#bk2} [calc] A distressed portfolio holds 40 equally weighted positions. If one position goes to zero, what is the portfolio loss?
   - [x] 2.5%
   - 1%
   - 4%
   - 40%
   > Each position is 1 / 40 = 2.5% of the portfolio, so losing one costs 2.5%.

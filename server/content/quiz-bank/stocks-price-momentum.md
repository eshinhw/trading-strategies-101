# Quiz

1. {#bk1} [calc] A stock was $50 twelve months ago, $62 one month ago, and is $60 today. What is its 12-1 month momentum return, measured from 12 months ago to one month ago?
   - 20%
   - −3.2%
   - [x] 24%
   - 12%
   > The 12-1 return skips the latest month: $62 / $50 − 1 = 24%.

2. {#bk2} [calc] A momentum strategy buys the best 12-month performer and shorts the worst, in equal dollar amounts. Over the next month the winner gains 2% and the loser gains 3%. What is the strategy's return on the long amount?
   - [x] −1%
   - +5%
   - +1%
   - +2%
   > The long earns +2% and the short loses 3%. The net return is 2% − 3% = −1% on each dollar per side.

3. {#bk3} [calc] A stock closed at $40 twelve months ago, $50 one month ago and $48 today. A momentum rule measures the return from 12 months ago to one month ago, skipping the last month. What is that return?
   - 20%
   - −4%
   - [x] 25%
   - 10%
   > ($50 − $40) / $40 = 25%. The latest month's fall to $48 is skipped.

4. {#bk4} [calc] A momentum portfolio is long the top 3 stocks and short the bottom 3, equally weighted within each side. The longs return +3%, +1% and +5% and the shorts return +2%, 0% and +4% next month. What is the long-short return?
   - +3%
   - [x] +1%
   - +9%
   - −1%
   > Long average = 3%. Short average = 2%. Long-short = 3% − 2% = +1%.

5. {#bk5} How does cross-sectional momentum differ from trend following in an individual instrument?
   - It reacts only to one asset's own price path
   - It buys the worst performers
   - It ignores past returns altogether
   - [x] It ranks assets against each other and holds the relative winners, rather than reacting to one asset's own price path
   > Cross-sectional momentum is a relative-strength approach, not an absolute-price approach.

6. {#bk6} What is a momentum crash?
   - A sudden stop in trading on the exchange
   - [x] A sharp loss when markets reverse and the recent losers, which the strategy is short, rebound the hardest
   - A period when all stocks fall equally
   - A loss caused only by high trading fees
   > After a market crash, the stocks that fell the most often bounce back the most, which hurts a momentum strategy short those losers.

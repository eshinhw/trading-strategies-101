# Quiz

1. {#bk1} [calc] A convertible bond with a $1,000 face value has a conversion price of $50. The stock trades at $58. What is its conversion value?
   - $1,000
   - $2,900
   - [x] $1,160
   - $20
   > Conversion ratio = $1,000 / $50 = 20 shares. Conversion value = 20 × $58 = $1,160.

2. {#bk2} [calc] A convertible bond with a $1,000 face value has a conversion price of $40. The stock trades at $35. What is its conversion value?
   - [x] $875
   - $1,000
   - $1,400
   - $25
   > Conversion ratio = $1,000 / $40 = 25 shares. Conversion value = 25 × $35 = $875.

3. {#bk3} [calc] A convertible bond with a $1,000 face value has a conversion price of $25. The stock trades at $32. What is its conversion value?
   - $1,000
   - $800
   - [x] $1,280
   - $40
   > Conversion ratio = $1,000 / $25 = 40 shares. Conversion value = 40 × $32 = $1,280.

4. {#bk4} [calc] A convertible bond trades at $1,200 while its conversion value is $1,160. What is the conversion premium?
   - 3.3%
   - [x] 3.4%
   - 40%
   - 16.0%
   > Premium = ($1,200 − $1,160) / $1,160 = 3.4%.

5. {#bk5} [calc] A $1,000 convertible converts at $62.50 per share. How many shares does one bond convert into?
   - 62.5
   - 8
   - 160
   - [x] 16
   > Conversion ratio = $1,000 / $62.50 = 16 shares.

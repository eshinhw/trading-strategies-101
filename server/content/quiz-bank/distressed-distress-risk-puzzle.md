# Quiz

1. {#bk1} [calc] Low-distress-risk stocks returned 12% a year and high-distress-risk stocks returned 4%. A long-short strategy buys the low-risk group and shorts the high-risk group in equal dollars. What is the spread return per dollar per side?
   - 16%
   - [x] 8%
   - 4%
   - 12%
   > 12% − 4% = 8%.

2. {#bk2} [calc] A high-distress-risk stock portfolio returns 4% while the low-risk portfolio returns 12%. The puzzle is that riskier stocks earned less. By how many percentage points did the riskier stocks fall short?
   - 3 percentage points
   - 16 percentage points
   - 0.33 percentage points
   - [x] 8 percentage points
   > 12% − 4% = 8 percentage points less for the riskier stocks.

# Quiz

1. {#bk1} [calc] A portfolio is 70% stocks returning 10% and 30% commodities returning 6%. What is the portfolio return?
   - 8%
   - 9.2%
   - [x] 8.8%
   - 7.4%
   > Return = 0.70 × 10% + 0.30 × 6% = 8.8%.

2. {#bk2} [calc] A portfolio is 80% stocks (15% volatility) and 20% commodities (20% volatility) with a correlation of 0.2. What is the portfolio volatility?
   - [x] 13.4%
   - 16.0%
   - 17.0%
   - 12.0%
   > Variance = (0.8 × 0.15)² + (0.2 × 0.20)² + 2 × 0.8 × 0.2 × 0.2 × 0.15 × 0.20 = 0.01792. Volatility = √0.01792 = 13.4%.

3. {#bk3} [calc] The same portfolio (80% stocks at 15% volatility, 20% commodities at 20% volatility) has a correlation of 0 instead. What is its volatility?
   - 13.4%
   - 14.0%
   - [x] 12.6%
   - 16.0%
   > Variance = (0.12)² + (0.04)² = 0.0160. Volatility = 12.6%.

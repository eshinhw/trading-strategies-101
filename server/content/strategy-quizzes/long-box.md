# Quiz

1. What is a long box mainly used for?
   - [x] To lock in a nearly risk-free fixed payoff or exploit small pricing differences, rather than to express a market view
   - To bet on a large rally by combining two calls so that the position gains whenever the stock rises sharply
   - To profit from a large decline, since the two put spreads in the position gain value as the stock falls
   - To collect income from a flat market, since all of the options in the box lose value as time passes
   > A box pays a fixed amount regardless of where the stock ends up.

2. Why does a box always pay out the same amount at expiration?
   - Because the stock price is fixed by the exchange at expiration, so the spreads always settle at the same level
   - [x] A bull call spread plus a bear put spread on the same strikes always pays the width between the strikes
   - Because it is a single option, so its payoff at expiration depends only on the strike and not on the stock
   - Because the stock must end at one of the strikes, which makes the combined value of the legs the same
   > The two spreads offset each other's dependence on the stock price.

3. How is a long box built?
   - Buy a call and a put at the same strike
   - Sell a straddle and buy a strangle at the same strike, so that the combined position pays a fixed amount
   - [x] Combine a bull call spread and a bear put spread on the same two strikes, same expiration
   - Buy two calls and sell one put at the same strike, so that the combined position pays a fixed amount
   > Four legs across two strikes.

4. What does a trader compare to see if a box is worthwhile?
   - The stock's expected direction, because the box pays more if the stock finishes above the higher strike
   - The stock's dividend, because the box pays more if a dividend is declared before the expiration date
   - The stock's volatility, because the box pays more if implied volatility rises before the expiration date
   - [x] The total cost of the four legs against the fixed payout equal to the strike width
   > If the box costs less than the payout, the difference is a locked-in profit.

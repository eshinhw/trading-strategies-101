# Quiz

1. When is a strap more appropriate than a straddle?
   - You expect the stock to stay flat, so you want an extra call to benefit from the passing of time
   - [x] You expect a big move but lean bullish about which direction is more likely
   - You lean bearish about the direction and want an extra put to profit from a decline in the stock
   - You want to sell volatility, so you want an extra short call to collect more premium from the options
   > A strap adds an extra call to tilt a straddle toward a rally.

2. How does a strap's payoff differ from a straddle's?
   - A decline makes more money than an equal-sized rally, because the extra option is a put rather than a call
   - It profits only when the stock rises
   - [x] A rally makes more money than an equal-sized decline, while the put still protects if the stock falls
   - It has limited profit on the upside, because the extra calls are offset by the sold options at the strike
   > The extra call skews the payoff toward the upside.

3. How is a strap built?
   - Buy 1 at-the-money call and 2 at-the-money puts with the same strike and expiration, tilting the position bearish
   - Sell 2 at-the-money calls and 1 at-the-money put with the same strike, collecting a larger premium up front
   - Buy 2 calls and sell 1 put
   - [x] Buy 2 at-the-money calls and 1 at-the-money put with the same strike and expiration
   > Two calls and one put give the bullish tilt.

4. What is the maximum loss of a strap?
   - [x] The total debit paid, which occurs if the stock finishes at the strike
   - Unlimited, because the extra calls keep losing value as long as the stock stays above the strike price
   - Zero, because the single put protects the position against any loss that the calls could suffer
   - Only the cost of the put
   > All options expire worthless at the strike, so the whole premium is lost.
